# 本地量化策略研究

用户要求使用自己的量化策略、收盘选股或本地 CSV 回测时：

1. 调用 `list_local_quant_strategies` 查明实际可用策略。不要把系统策略库查询当成本地源码目录查询。
2. 根据用户目标选择一项 `close_only_supported=true` 的策略，调用
   `load_local_quant_strategy` 读取实际表达式、源码版本和决策频率。用户未指定时，
   选择一项规则清晰的可用策略，说明理由并执行，不需要逐步索要确认。
3. 调用 `backtest_local_quant_strategy`，指定评估起止日期，以及可复查的 `screen`。
   筛选依据是当时已收盘数据；工具隔离 `next_day_*` 结果列。需要精确研究某些股票时用 `codes`。
   默认 `data_quality=strict`；无效价格会阻止回测。如采用 `quarantine`，必须说明隔离了多少
   条行情并链接 excluded_bars.csv，不能把缺失价格补成成交。
4. 工具的 `metrics` 是共享资金组合收益，费用及滑点已由引擎计算。读取
   `artifacts/summary.md` 或 `summary.json`，结合 `candidates.csv` 与 `fills.jsonl` 解释结果。
5. 汇总实际区间、筛选与持有规则、初始/期末权益、总收益、回撤、夏普、成交次数、
   期末持仓，并提供报告路径。失败、无候选、无成交必须如实报告。不可用文本估算冒充回测。

月度策略仅在月末更新目标，日度策略按收盘更新。默认主板股票池、收盘高于 MA20、
按 20 日动量保留 50 个候选、最终最多 10 个持仓。离开候选池会在策略下一次决策时
退出目标。`min_momentum20` 是小数收益率；换手率阈值沿用 CSV 的百分数口径。
评估首日按此前已知目标初始化。缺失行情或零成交量日不成交；月度受阻指令当日
失效，等待下次月度决策；日度策略依下一收盘目标重新决策。执行跳过记录见 execution_skips.csv。

竞价隔夜策略依赖次日竞价信息；目录会标注该策略不适用于当前收盘工具。
不要为了运行它，使用次日信息伪造当日收盘信号。

策略指标沿用受信任源码，交易记账统一为项目引擎，因此不要求与原脚本的简化收益
算法数值相同。期末未平仓头寸按收盘估值，不虚构期末强制卖出。历史复权、ST/退市
状态与股票池偏差尚未独立校验；未经样本外和前向验证，不宣称稳定盈利。
